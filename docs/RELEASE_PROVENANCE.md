# Release Provenance

This package incorporates the original Basic_PDF_RAG starter, the recorded hybrid
retrieve function, neighboring-chunk display changes and the concise prompt used
in development. It is not a byte-for-byte copy of the final Windows app.py because
that file was not uploaded. Local deterministic checks validate specific helper
behavior; they do not establish end-to-end parity with the developer's tested app.
